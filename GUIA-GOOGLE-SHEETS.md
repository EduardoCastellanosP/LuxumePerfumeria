# Cómo actualizar los perfumes (para el cliente)

Todo se hace en la hoja de Google **LUXUME Catálogo**. La página se actualiza sola en máximo 1 hora.

## Columnas
| Columna | Qué poner |
|---|---|
| mostrar | `SI` para mostrarlo · `NO` para ocultarlo (no se borra) |
| slug | **No tocar** en perfumes existentes. En uno nuevo, déjalo vacío |
| nombre, marca | Obligatorios |
| tipo | `Original` o `1.1` |
| genero | `Mujer`, `Hombre` o `Unisex` (Unisex sale en las dos) |
| linea | `Árabe`, `Diseñador` o `Nicho` |
| precio | Solo el número: `150000` (vacío = "Consultar precio") |
| ml | `100` si se deja vacío |
| familia | Texto libre: `Oriental dulce amaderado` |
| grupos | Separados por coma: Amaderado, Oriental, Floral, Cítrico, Fresco, Dulce |
| ocasiones | Separadas por coma: Día, Noche, Oficina, Cita |
| temporada | `Todo el año`, `Clima cálido`, `Clima fresco` |
| resumen | Una frase corta para la tarjeta |
| descripcion | Texto largo del detalle |
| salida, corazon, fondo | Notas separadas por coma |
| notas_principales | Solo si no hay pirámide (salida/corazón/fondo) |
| destacado | `SI` = sale en el inicio (máximo 4) |
| fotos | Enlaces de Google Drive, uno por línea (Ctrl+Enter dentro de la celda) |

**El orden de las filas es el orden en la página.**

## Fotos
1. Súbelas a la carpeta de Drive **LUXUME Fotos** (en JPG o PNG, no HEIC).
2. Clic derecho en la foto → Compartir → Copiar enlace.
3. Pégalo en la columna `fotos`. La primera foto es la principal.

No hay que recortarlas ni editarlas: la página las ajusta sola sin cortar el frasco.
